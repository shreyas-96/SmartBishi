# SmartBishi 💰

**SmartBishi** is a professional Android application designed for managing "Bhishi" (local collection/saving schemes) with ease. It provides a comprehensive solution for agents to track deposits, withdrawals, and generate detailed reports while ensuring data is synced across devices using Firebase.

## 🚀 Features

- **Transaction Management**: Easily record deposits and withdrawals for customers.
- **Detailed Reporting**:
    - Daily Collection Reports
    - Weekly Summaries
    - Monthly Detailed Reports
    - Individual Customer Statement Reports
- **PDF Generation**: Generate professional PDF receipts and reports directly from the app.
- **WhatsApp Integration**: Automatically send transaction details to customers via WhatsApp.
- **Offline Mode**: Work without internet connectivity; data automatically syncs once you're back online.
- **Route Management**: Organize your collections by routes for better efficiency.
- **Secure Authentication**: Protected by Firebase Authentication to keep your data safe.
- **Modern UI/UX**: Premium design with Material 3 components and full support for Dark Mode.
- **Local Database**: Powered by Room Database for fast local access and offline stability.

## 🛠 Tech Stack

- **Language**: Java
- **Database**: Firebase Realtime Database & Room Database
- **Authentication**: Firebase Auth
- **Networking**: OkHttp
- **Reports**: Custom PDF Generation Engine
- **UI Components**: Material Design 3, CoordinatorLayout, RecyclerView

## 📦 Getting Started

### Prerequisites
- Android Studio Iguana or newer
- JDK 11 or higher
- A Firebase project setup

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/shreyas-96/SmartBishi.git
   ```
2. Open the project in Android Studio.
3. Add your `google-services.json` file to the `app/` directory.
4. Build and run the application.
